# Computer Networks Lab

This repository contains **Computer Networks laboratory programs implemented in C**.  
The programs demonstrate various concepts and protocols commonly studied in a Computer Networks course.

## 📚 Experiments

| Experiment | Topic | Source Code |
|------------|-------|-------------|
| Experiment 2 | Bit Stuffing & Character Stuffing | [`Experiment-2/`](Experiment-2/) |
| Experiment 3 | Checksum | [`Experiment-3/checksum.c`](Experiment-3/checksum.c) |
| Experiment 4 | Hamming Code | [`Experiment-4/hamming_code.c`](Experiment-4/hamming_code.c) |
| Experiment 5 | Cyclic Redundancy Check (CRC) | [`Experiment-5/crc.c`](Experiment-5/crc.c) |
| Experiment 6 | Go-Back-N ARQ | [`Experiment-6/go_back_n.c`](Experiment-6/go_back_n.c) |
| Experiment 7 | Selective Repeat ARQ | [`Experiment-7/selective_repeat.c`](Experiment-7/selective_repeat.c) |
| Experiment 8 | Stop-and-Wait Protocol | [`Experiment-8/stop_and_wait_protocol.c`](Experiment-8/stop_and_wait_protocol.c) |

## 🛠️ Technologies Used

- **C Programming**

Make sure GCC is installed and added to your system's PATH.

### Compile

For example, to compile the Checksum program:
